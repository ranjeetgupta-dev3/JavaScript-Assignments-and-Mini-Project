# JavaScript Assignments and Capstone Mini Project

This repository contains my JavaScript practical assignments and capstone mini project completed as part of the JavaScript curriculum.

## 📚 Assignments

### Assignment 1 – Variables, Data Types, and Console Operations
Demonstrates:
- `var`, `let`, and `const`
- Different data types
- `typeof` operator
- Console operations

### Assignment 2 – Operators, Expressions, and Input Handling
Demonstrates:
- `prompt()`
- Type conversion using `Number()`
- Arithmetic and assignment operators
- Tip and bill calculation

### Assignment 3 – Conditional Logic Implementation
Demonstrates:
- `if...else`
- `switch`
- Ternary operator
- Grade and pass/fail evaluation

### Assignment 4 – Loop Control Structures
Demonstrates:
- `for` loop
- `while` loop
- `do...while` loop
- `break`
- `continue`

### Assignment 5 – Function Architecture and Scope
Demonstrates:
- Regular functions
- Arrow functions
- Default parameters
- Function scope
- Block scope

### Assignment 6 – Arrays, Objects, and Core Methods
Demonstrates:
- Arrays of objects
- `forEach()`
- `filter()`
- `map()`
- Object properties and array manipulation

## 🚀 Capstone Mini Project

### Interactive Product Inventory & Analytics Dashboard

The capstone project combines the major JavaScript concepts covered throughout the curriculum into a single interactive application.

### Features

- User input using `prompt()`
- Explicit type conversion
- Product inventory using arrays and objects
- Input validation
- Dynamic product categorization
- Budget, Standard, and Premium categories
- Inventory value calculation
- Affordable product filtering
- Formatted inventory reports
- Discount calculation
- Use of loops and array methods

### Technologies Used

- HTML5
- JavaScript
- Browser Console

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the required JavaScript file or the capstone project's `index.html`.
4. For the capstone project, open `index.html` in a web browser.
5. Open the browser Developer Tools using `F12`.
6. Go to the **Console** tab to view the JavaScript output.
